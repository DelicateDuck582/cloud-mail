## 背景与既定结论

- CloudMail：CF Workers + D1 + KV + 腾讯云 COS 私有桶 + cos-exchange 前置代理；REST+JWT；**不保存原始 MIME**（需重建）。
- TB 145+ 原生支持 EWS（SOAP/XML over HTTPS），可手动指定 URL+凭据 → 唯一纯 serverless 的 TB 原生路线。
- CF 账户为 **Free 计划**（已核实：CPU 10ms/请求只计计算、密码哈希 SHA-256 <0.1ms、KV 写 1000/天、子请求 50/次、请求 10 万/天）——方案按此设计可行。
- 分支：从 `origin/attachment-manager` 新开 `ews-thunderbird`；只推 origin fork，**不做上游贡献**；git/wrangler 走 `http://127.0.0.1:10808` 代理。

## Free 计划硬约束适配

- 经 EWS 上传/下载的单附件默认 3MB 阈值（常量可配，实测校准；升 Paid 可放宽），超限返回标准 EWS Fault 引导 Web 端。
- EWS SyncState 存 **D1**（新表），KV 仅存低频 EWS 会话。
- 所有 EWS 列表分页 ≤50；内嵌图 ≤10 次 COS 读/请求。
- 验收用 wrangler tail 核对 CPU <10ms。

## 阶段 A：安全修复内容（P0–P3 全部）

**mail-worker**：① P0 isSafeUrl 空白字符绕过（服务端+前端双份，规范化+白名单协议）；② 附件 MIME 白名单归一 + Content-Disposition 清洗 + 扩展名白名单；③ clearTrash 分批（LIMIT 90、inArray ≤90）+ manage 系列入参上限 + star 清理 + 「无剩余附件才删邮件」判定统一；④ key 归属 IDOR（selectOneByKeys 加 userId、signContent 只签本人 key、引用计数按 att_id）；⑤ /email/send 请求体上限 413 + 发信附件总量校验；⑥ 入站 TextDecoder {stream:true} + rawSize 前置拒绝；⑦ Resend/Svix 验签修复（whsec_ base64、NaN 拒、timingSafeEqual、未配置 fail-closed）；⑧ getBucketUsage KV 缓存 + 页数上限；⑨ /att/* 纳入 requirePerms（att:query/att:delete）；⑩ /email/detail 权限拆分（att:all 只给附件元数据）；⑪ KV 回退批量删除小批串行；⑫ security.js exclude 精确路径（删 /test、oauth 只放行 */login）；⑬ JWT exp、genRandomPwd 拒绝采样、settingService.get 浅拷贝、/att/delete 响应统一、引用计数事务化、migrateFallbackBatch 提前、toImageUrlHtml 校验前置、cron 补 */30、前端重复按钮/i18n 文案。

**cos-exchange（doc/cos-proxy-worker.js）**：/browse 前缀白名单（禁 attachments/、static/）；/temp 会话改随机 sid+KV；附件响应非白名单 MIME 强制 octet-stream+attachment + CSP；/static/ 收紧为背景图前缀白名单 + CORP；totp fail-closed；空目录不回显 COS XML；域名环境变量化；嗅探结果落 KV；TEMP_PASS 改 Secret（文档）。

## 阶段 B：EWS 实现

新增 `mail-worker/src/ews/`：入口拦截 `POST /EWS/Exchange.asmx`（Hono 之前）；HTTP Basic 认证（复用 SHA-256 校验 + per-IP 限流）；fast-xml-parser 解析 + 手写 XML 模板；操作子集 GetFolder/SyncFolderHierarchy/SyncFolderItems（分页）/GetItem/GetAttachment（3MB 阈值、服务端直读 COS、userId 归属校验）/CreateItem·SendItem（走现有 emailService.send 管线）/UpdateItem(ReadFlag)/DeleteItem(软删)；其余操作返回标准 Fault（TB 退化轮询）。D1 迁移：email 表加 update_time（已读/软删 touch，兜底 create_time）+ ews_sync_state 表。mime-build.js：headers（RFC2047 Subject 等）+ multipart/alternative+related（cid 内嵌图）+mixed（附件 base64）。README 补 TB 配置说明。
