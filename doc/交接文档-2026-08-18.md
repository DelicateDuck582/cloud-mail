```
浏览器
 ├─ mail.<域名>      → Cloudflare Worker (mail-worker)  邮件系统（D1 + KV + R2/AI/assets）
```

## 4. COS 容错架构（两分支一致）

```
COS 正常        → 附件存/读 COS（HMAC 短期签名 + 代理 Worker）
COS API 失败    → 自动回退 KV（5 分钟故障窗口，读写都回退，打 storage=fallback 标记）
                  · 历史 COS 附件 → 下载/打开提示「文件暂时无法访问--COS错误」(503)
                  · 邮件内嵌图片  → 前端 toast 同文案
COS 恢复        → 访问到的附件立即回迁；cron(*/5) 批量回迁（cursor 分页，≤30 个/次）
                  删除附件双删（COS + KV）防残留
```

涉及：`r2-service.js`（回退/回迁/双删）、`sign-utils.js`（URL 按存储生成）、`r2-api.js` + `index.js`（503 提示 + cron）、`att-service.js`（用量统计触发故障标记）、`shadow-html` + i18n（前端 toast）、`wrangler.toml`（新增 `*/5 * * * *`）。

## 5. 网盘 /browse 安全防护（cos-proxy-worker.js）

- **BROWSE_PASS 必填**：未配置直接拒绝，防误配整桶裸奔；cookie 为 HMAC 指纹（非明文），HttpOnly + Secure + SameSite=Lax，恒定时间比较
- **登录**：Turnstile 人机验证（可选）+ 同 IP 5 次/10 分钟锁定 + 1s 延迟 + 失败记录定期清理（防内存撑爆）
- **限流**：`/browse/api/list` 40 次/分、`/browse/api/file` 120 次/分（per-IP）
- **路径穿越拦截**：绝对路径 / 反斜杠 / `../` 一律 400
- **错误脱敏**：列表失败只回 `error` 字段（不泄露 COS 域名/签名中间值）
- **COS 健康探测**：`/browse` 页面请求先探测 COS（30 秒缓存，MinList），失败返回 503「COS对象存储错误，暂时关闭服务」；不泄露细节、不可放大流量
- **Cache-Control private**：附件与网盘文件响应均 `private`（仅浏览器缓存，禁止 CF 边缘缓存绕过验签/密码）

## 6. mail-worker 安全加固清单

- SQL 全参数化（drizzle / `prepare().bind()`）；全局错误脱敏（不泄露内部信息）
- 登录防爆破（5 次/10 分钟 + 延迟）；注册/加号 Turnstile + per-IP 验证记录
- `/init` 独立 `INIT_SECRET` + per-IP 限流；webhook 用 `RESEND_SIGNING_SECRET` 验签（Svix v1, 前缀 + 恒定时间比较）
- CORS 白名单（仅本机 + 站域名）；附件直读强制 HMAC 签名
- 邮件内容 XSS 白名单清洗（入库 + 前端渲染兜底）；TG 预览 token 7 天 TTL + no-store
- 入站邮件 25MB / 附件 20 个上限；发信前附件数量限制（10 图 + 10 附件）
- 附件/网盘响应 `Cache-Control: private`（防边缘缓存绕过）
